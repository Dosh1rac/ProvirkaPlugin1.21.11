# CheckPlayer

Простой и настраиваемый плагин для Paper, предназначенный для проверки игроков администрацией.

## Возможности

* Заморозка игрока во время проверки.
* Повторяющиеся уведомления в чате.
* Заголовок (Title) при начале проверки.
* Настраиваемые сообщения через `config.yml`.
* Настраиваемые эффекты (`Blindness`, `Nausea`).
* Команда завершения проверки.
* Автоматическая перезагрузка конфигурации.
* Защита от повторного начала проверки.

## Команды

| Команда                 | Описание                   |
| ----------------------- | -------------------------- |
| `/provirka <игрок>`     | Начать проверку игрока     |
| `/provirkastop <игрок>` | Завершить проверку         |
| `/checkreload`          | Перезагрузить конфигурацию |

## Права

| Право             | Описание                   |
| ----------------- | -------------------------- |
| `provirka.use`    | Начать проверку            |
| `provirka.stop`   | Завершить проверку         |
| `provirka.reload` | Перезагрузить конфигурацию |

## Конфигурация

Плагин полностью поддерживает настройку через `config.yml`.

Можно изменить:

* сообщения;
* количество повторов;
* интервал отправки сообщений;
* Title;
* эффекты;
* их длительность и уровень.

## Совместимость

* Java 21
* Paper 1.21.x

## Установка

1. Скачайте последнюю версию плагина.
2. Поместите `.jar` в папку `plugins`.
3. Перезапустите сервер.
4. Настройте `config.yml` при необходимости.
